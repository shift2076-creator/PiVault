After a fresh install, download the file again and trust it on each device, because a new install can create a new authority.

Firefox on desktop
  1. Open Settings, then Privacy & Security, then Certificates, then View Certificates.
  2. On the Authorities tab, choose Import, select pivault-root.crt, and tick "Trust this CA to identify websites".
  3. Reload PiVault.
Chrome or Chromium on Linux
  1. Open Settings, then Privacy and security, then Security, then Manage certificates.
  2. On the Authorities tab, choose Import, select pivault-root.crt, and tick "Trust this certificate for identifying websites".
  3. Reload PiVault.
Chrome or Edge on Windows
  1. Open pivault-root.crt and choose Install Certificate.
  2. Choose Current User, then Place all certificates in the following store, then Browse, then Trusted Root Certification Authorities, then Finish.
  3. Restart the browser and reload PiVault.
Chrome or Safari on macOS
  1. Open pivault-root.crt. Keychain Access adds it to the login keychain.
  2. Open the certificate whose name starts with Caddy Local Authority, expand Trust, and set "When using this certificate" to Always Trust. Enter your password when asked.
  3. Reload PiVault.
Android
  1. Download the file on the phone.
  2. Open Settings, then Security (or Security and privacy), then Encryption and credentials, then Install a certificate, then CA certificate. Menu names vary by phone.
  3. Select pivault-root.crt from Downloads and confirm.
  4. Reload PiVault.
iPhone or iPad
  1. Open the download link in Safari and allow the configuration profile download.
  2. Open Settings, then General, then VPN & Device Management, and install the PiVault profile.
  3. Open Settings, then General, then About, then Certificate Trust Settings, and turn on full trust for the Caddy root.
Any other browser or device
  1. Look in the browser's settings for "certificates" or "authorities", and find where it imports a certificate.
  2. Import pivault-root.crt. If the browser asks what to trust it for, choose identifying websites.
  3. If the browser has no such option, it uses the system store. Install the file through the operating system instead, using the steps for its system above.
  4. Check the fingerprint above, then reload PiVault.
